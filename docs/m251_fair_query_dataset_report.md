# M-25.1 Fair Query Dataset Report

## Frozen V2 Design

V2 contains 24,000 train, 3,000 validation, 3,000 calibration, 6,000 development, and 6,000 blind requests. Blind text and targets are physically separated. All ten pairwise prompt intersections are zero.

The manifest binds inventories, split definitions, zero-skill assignments, language-transfer assignments, file hashes, and blind hashes. Eighteen query-free skills cover all six families. Variable assignments, RU-only/EN-only training groups, catalog lexical holdout, true lexical OOD, heldout templates, heldout clause order, and composed conditions are generated by distinct code paths.

`TRUE_LEXICAL_OOD` appears only in blind and is absent from train, validation, calibration, development, catalog aliases/examples/names/effect summaries, and all skill-corpus conditions. `CATALOG_LEXICAL_HOLDOUT` is absent from training queries but uses individual trusted catalog lexemes without copying complete aliases or examples.

Unknown and ambiguous requests use the same neutral wrapper, suffix, punctuation, and template distributions as positives. They state copy, swap, sort, compare, multiplication, register-E, conditional, or one-field-incomplete requests without announcing a negative label.

Hard rows include target, installed counterfactual neighbor, one changed conceptual field, hidden pair ID, and a matched counterfactual surface. Pair IDs and changed-field annotations are never model-visible.
