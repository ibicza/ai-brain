# M-33.6c future M-33.6d candidate strategy

The future pool is metadata-only: 16 optional families from 14 organizations. No candidate is required. A future probe may read only coordinate existence, POM bytes, POM license/SCM metadata, declared Java version and checksum/signature endpoint availability.

It must not inspect source-JAR bodies or listings, SCM tree bodies, Java files, callable counts, source hashes or parser/evaluator output before the M-33.6d freeze.

Synthetic scenarios cover 0%, 25% and 50% failures, license review, SCM correspondence failure, checksum absence, duplicate organizations and root-contribution imbalance. Every simulation retains at least three eligible roots and the preferred five-root margin. The pool itself is not frozen by M-33.6c.
