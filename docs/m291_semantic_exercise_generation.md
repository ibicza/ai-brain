# M-29.1 semantic exercise generation

Runtime exercise generation selects from the verified precompiled catalog and performs no chemistry execution. A semantic key binds family, subject/predicate, numeric givens, source/target units, entity basis, precision, answer semantics and graph.

The catalog contains 2,000 distinct semantic keys and 2,000 distinct graph/value combinations. Development acceptance presents 5,000 instances with 3,932 distinct question strings and no more than three RU/EN presentation variants per semantic key.

Formula scope is bounded to reviewed exercise formulas plus explicitly labelled formal structural formulas. Arbitrary syntax is never described as a reviewed real compound.
