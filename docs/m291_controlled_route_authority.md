# M-29.1 controlled route authority

`EducationalRouteReceipt` binds the original request hash, controlled parser version, route kind, session, public presentation or prepared response, requested action, catalog/domain dependency snapshot, timestamp and receipt hash.

GENERATE_EXERCISE and precompiled EXPLAIN load verified catalog material without execution. A new EXPLAIN returns PREPARED. CHECK_ANSWER, HINT and SHOW_SOLUTION require a bound session and its state policy.

Changing route kind, session or dependency snapshot invalidates the receipt. The administrative compile-catalog command is explicit and is not reachable from ordinary controlled text.
