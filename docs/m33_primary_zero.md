# Нулевой класс: первый обученный визуальный блок

2026-10-08. v3: `BOUNDED_SYNTHETIC_GATE_PASSED_NOT_PRODUCTION`.
Это отдельный эксперимент, не школьная база знаний, не закрытие строгого M33/U
и не допуск ответов/новых фактов в production.

## Обученные навыки и граница

Шесть прототипов: круг, овал, квадрат, прямоугольник, треугольник, пятиконечная
звезда. Шесть цветов: красный, синий, зелёный, жёлтый, оранжевый, фиолетовый.
Количество фигур 0–5; `UNKNOWN` для закрытой/отсутствующей картинки и отсутствия
однозначной общей прототипной метки цвета/формы.

Прототипные метки — наиболее конкретные названия курса, не взаимоисключающие
универсальные математические категории. Квадрат остаётся прямоугольником;
утверждение обратного не обучалось. Проверка надкатегорий/иерархии не реализована.
Вопросы ограничены явным небольшим русским стартовым набором. Это не свободный
диалог, OCR, знание слова «арбуз» или понимание произвольной страницы.

## Код и архитектура

- `src/ai_brain/training/primary_zero.py`: сцены, рендер/oracle, пиксельные SHA,
  разбиения, модель, отказ и метрики.
- `scripts/m33_primary_zero_pilot.py`: изолированное обучение и проверка.
- `tests/test_primary_zero.py`: контракты, независимый подсчёт связных пиксельных
  компонентов и отрицательные контроли.

RGB 96×96 → CNN → 144 пространственных токена. Они и русские стартовые слова
идут в общий для трёх навыков `TinyCausalTransformer` существующей архитектуры.
Все веса новой модели случайные; внешних предобученных весов нет. Это общее ядро
пилота, не объединение ранее обученных моделей и не доказательство всей roadmap.
Существующие веса, удалённый checkout и M34 не заменялись.

v3 добавляет обучаемое резюме слов вопроса и вспомогательную intent-цель.
Тип задания является только учебной целью, **не входом** при ответе.
Входы модели — пиксели и слова; scene ID, координаты oracle, gold и готовый
подсчёт объектов не передаются. Словарь строится по учебным формулировкам.

Выбор ответа требует согласия исходного и зеркального изображения, сохраняет
меньшую уверенность и переносит остальную массу в неопределённость. Пороги
выбираются отдельно по навыкам на calibration. Это политика выбора, не
вероятность истинности и не гарантия отсутствия будущих ошибок.

## Данные, процедура, результаты

Только собственные процедурные рисунки: PDF, приватные M33 gold и агентские
псевдоподписи не использовались. v3: 8000 train-сцен / 24000 заданий; отдельно
по 700 сцен / 2100 заданий в dev, calibration, final и transfer. Dev выбирает
checkpoint по cross-entropy; calibration выбирает пороги; final/transfer
оцениваются после их фиксации. Финальные вопросы — новые сочетания учебных слов.

Train-стили: заливка, контур, заливка с тёмным контуром. Transfer добавляет
текстурированный фон. Сцены частично выравнивают общую закрашенную площадь между
разными количествами; контрфактические серии меняют ровно проверяемый признак.
Всё это один генератор, не независимый учебник/фотографический датасет или
слепое испытание M33. Постоянные empty/masked/missing-контроли повторяются между
разбиениями явно и не считаются независимыми доказательствами. Семантическая
дедупликация произвольных внешних изображений ещё не реализована.

До обучения записан gate для каждого навыка: ≥50 принятых ответов, 0 ложных
утверждений, ≥80% правильных ответов среди разрешимых задач, ≥90% верных отказов
в final и transfer; ≥80% в контрфактических сериях; падение разрешимой полноты
≥15 процентных пунктов при удалении/подмене картинки. «Не знаю» на всё — провал.

Полнота ниже — доля **всех разрешимых** задач с правильным ответом.

| Навык | Final: полнота | Transfer: полнота | Ошибочные принятые ответы |
| --- | ---: | ---: | ---: |
| Счёт 0–5 | 100% | 100% | 0 / 0 |
| Название формы | 100% | 99,71% | 0 / 0 |
| Цвет | 98,17% | 98,84% | 0 / 0 |

4200 final/transfer-заданий, 2333 принятых ответа, 0 ложных утверждений.
Общая разрешимая полнота 99,48% / 99,58%; корректный отказ 100% в обоих наборах.
В 540 контрфактических заданиях приняты 537 правильных ответов, ошибок 0.
Без картинки разрешимая полнота 0%; с подменённой картинкой 6,14% / 6,57%.
Single-view модель до политики дала одну ошибку в transfer, которую политика
отсеяла. Ноль ошибок на конечном зависимом наборе не означает «модель не врёт»
на любых источниках. Минимальная полнота по метке: зелёный 93,04%; прочие ≥99%.

v1/v2 остаются `REJECTED_NOT_PRODUCTION`: в v1 ни один навык не прошёл gate,
в v2 прошёл только счёт. Между итерациями менялось несколько факторов, поэтому
причинный эффект отдельной доработки не установлен. Ошибки final не добавлялись
в train; следующие итерации использовали новые seeds/сцены.
