# M-33.6c license document roles

License-like paths are classified before evidence fusion as `PROJECT_LICENSE`, `MODULE_LICENSE`, `NOTICE`, `THIRD_PARTY_LICENSE`, `DEPENDENCY_LICENSE`, `COPYRIGHT_NOTICE` or `UNKNOWN_LICENSE_DOCUMENT`.

Root and source-JAR `META-INF` licenses are project channels. Module paths remain module channels. NOTICE, dependency inventories, documentation/vendor licenses and copyright headers are never compared as the project license. The six-candidate inventory has zero unresolved roles.
