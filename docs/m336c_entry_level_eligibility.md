# M-33.6c entry-level eligibility

Every Java archive entry receives a `SourceEntryEligibility` binding its raw and canonical hashes, authenticity, correspondence class, authorized scopes, publication targets, include/exclude decision, reason and receipt hash. The selected subset has its own deterministic manifest hash.

Raw/canonical/relocated/generated correspondence is accepted when authenticity and authorization close. An authenticated Maven source archive can retain an unmatched or ambiguous entry for explicit local analysis as a visible single-channel decision. Exclusions are counted and never silent.

For the disclosed corpus the result is 1,684 total, 1,684 analysis-eligible, 0 raw-publication-eligible and 0 excluded entries. The two historically unmatched generated files are authenticated by the Maven source-archive channel; they are not misrepresented as SCM matches.
