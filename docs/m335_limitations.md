withheld with typed resolution reasons. Search alias lookup does not infer an
overload when more than one candidate remains. Same runtime binary identity
across roots is withheld rather than selecting a classpath winner. M-33.5 uses
only the disclosed Apache regression corpus and makes no untouched/final claim.

refusal, political, ideological, NSFW, personality or topic restriction was
added.
