# M-33.6g limitations

The public pack proves integrity, installation compatibility, and offline runtime use; it intentionally cannot reconstruct source-to-knowledge production by itself. Full replay requires the separately authorized private manifest, the exact external sealed vault, and the frozen JDK.

R22 changes only the publication architecture. It does not improve, weaken, or reinterpret R21 selector, compilation closure, trust, field-evidence, SPDX, authority, correspondence, registry, vault, or packability semantics. Fresh final acquisition remains forbidden until a valid Q22 and F22 exist.
