# M-28 Chemistry Limitations

This is not a general chemistry assistant. Only the 33 approved elements are calculation-supported. Atomic weights follow a frozen explicit policy; conventional values are not exact natural constants.

Formulas are neutral and syntactically bounded. There are no charges, hydrates, isotopes, reaction balancing/prediction, organic nomenclature, ionic equations, oxidation states, pH, equilibrium, kinetics, thermodynamics, or quantum chemistry.

The trusted runtime has no chemistry web access, automatic memory writes, model-generated trusted facts, hidden multi-step plans, or neural execution. Results depend on the selected source snapshot and policy.
