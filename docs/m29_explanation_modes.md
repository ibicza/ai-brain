# M-29 Explanation Modes

Supported deterministic modes are `CONCISE`, `FULL`, `CHECK_ONLY`, `HINT_ONLY`, and `SOLUTION_AFTER_ATTEMPT`.

RU/EN output maps rendered numbers, formulas, units, warnings, and citations to graph node IDs. Full/concise explanations retain source hashes and graph/result hashes. A full solution requested through `SOLUTION_AFTER_ATTEMPT` requires an observed attempt.
