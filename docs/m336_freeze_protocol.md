# M-33.6 freeze protocol

The dedicated protocol binds E14, the branch name, the excluded M-33 Outcome-C
commit, the exact F15/H15/E15 subjects, direct-parent/no-merge topology, H15 and E15
path allowlists, the frozen implementation prefixes, branch/upstream equality, and
the complete role manifest derived from Git objects.

Unknown H15 paths fail classification. Protected disclosure tokens are derived from
the actual H15 source, receipt, selector, census, production, candidate, oracle,
golden, evaluation, approval, installation, and decision artifacts, then searched in
all F15 blobs. A caller can add tokens but cannot remove the derived set. Neutral
all-zero audit blobs may be byte-reused.

E15 is verified post-commit because embedding a commit's own SHA in its own bytes is
cryptographically circular. The committed evidence binds the exact E14/F15/H15
chain and self-resolving E15 rule; the post-commit verifier resolves E15 from Git,
checks upstream equality, and emits the exact receipt.
