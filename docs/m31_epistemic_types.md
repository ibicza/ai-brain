# Epistemic types

The explicit classes are DETERMINISTIC, EMPIRICAL, APPROXIMATE, HEURISTIC,
NORMATIVE, INTERPRETIVE, and CONTESTED. Empirical, interpretive, and contested
records cannot become executable rules. Approximate rules require stated
approximation conditions. Non-deterministic rules require reviewed policy
authority; normative rules must identify their authority context. Heuristics
cannot be exact algorithms. Procedures are executable descriptions only when
deterministic and still require installed external authority for each invocation.
