# M-33 limitations

M-33 is a bounded black-box proof, not open-web autonomy. The final selector
list and authority domains are closed, acquisition is offline after snapshot,
and runtime has no network access.

Natural-language extraction is intentionally conservative. The frozen patterns
cover exact definitions, bounded affine equations, and structurally explicit
API signatures. Narrative causality, interpretation, implicit taxonomy,
cross-sentence relations, complex mathematical notation, and API declarations
split across unsupported layouts may remain `REVIEW_REQUIRED`,
`UNSUPPORTED_KNOWLEDGE_KIND`, or `NEEDS_NEW_CAPABILITY`. Lower recall is an
acceptable Outcome B; guessing is not.

The typed solver is affine and exact-rational only. It rejects nonlinear forms,
dimension mismatch, incompatible units, absent applicability conditions, zero
division, and violated ranges. No Java compilation/execution capability is
included. Compile/run requests therefore return `NEEDS_NEW_CAPABILITY`.

No moral, moderation, NSFW, political, ideological, topic, personality, or
generic harmful-content policy is present. Abstention is based only on evidence,
authority, ambiguity, conflict, currentness, applicability, and capability.

## Final black-box result

The frozen compiler failed the ordinary four-bundle build at the first
kinematics bundle with `approved proposals contain a conflicting semantic
identity`. The sealed evaluator also classified 832 Java proposals as wrongly
automatically source-entailed because the production proposal location and the
independently authored signature location did not agree. No frozen parser,
regex, threshold, schema, provider, capability, or evaluator was changed in
response.

The 12,299 non-document segments contain 5,818 exact duplicates, a rate of
0.473047 against the sealed maximum of 0.02. Most are repeated line-level Java
syntax and documentation boilerplate, but the threshold is intentionally not
reinterpreted after source reveal. Kinematics field evidence is incomplete by
4 fields and Java by 51 fields. History produced no automatically usable
records, so the independent metric denominators are `N/A` rather than synthetic
perfect scores.

To prove fail-closed runtime behavior without bypassing the frozen compiler,
H12 compiled and installed four content-addressed packs containing no approved
source proposals and a mandatory executable abstention test. All 500 semantic
held-out keys therefore produced the expected conservative status, but trusted
coverage is zero. This is a safety result, not evidence that cross-domain
extraction succeeded. M-33 consequently selects Outcome C and does not
recommend proceeding to M-34 from this branch.
