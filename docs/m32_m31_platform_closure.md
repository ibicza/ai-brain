# M-32 closure of the M-31 platform

M-32 adds a chemistry-free provider boundary and generic education/conversation facades. Taxonomy and quantity/equation packs execute the same present, parse, grade, hint, explain, replay, progress, and controlled-conversation flow without subject-specific modules.

The legacy M-30 chemistry facade remains for compatibility. Chemistry implementation details are behind `ChemistryEducationalDomainProvider`; new generic paths depend only on `EducationalDomainProvider` and installed pack data.

IR, provider, capability, domain-registry, and progress schemas are versioned independently. M-31 v1 artifacts remain in place while v2 packs live at parallel paths.
