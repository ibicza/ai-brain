# M-33.6e limitations

- Metadata-only risk filtering cannot establish final callability, license
  eligibility, SCM correspondence, or selectable capacity.
- A metadata-qualified candidate may fail after the one global acquisition; it
  is still disclosed and cannot be replaced or reacquired.
- A crashed reserved selector cannot be rerun. That intentionally converts the
  run to Outcome C.
- Unknown legal applicability remains review-required for affected files.
- Semantic evaluation covers the frozen Java declaration/evidence policy, not
  arbitrary Java behavior.
- Raw source and excerpts are intentionally non-public even when local analysis
  and derived-pack publication are authorized.
- M-33.6e proves Java only. The final four-domain proof belongs to M-33.7; M-34
  remains unstarted.
