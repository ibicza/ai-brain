# Контролируемый язык Stage-1 v1: RU

Команда обязана явно указывать действие, все источники, приёмник для переноса, сохраняемые без изменений регистры, условие остановки и порядок фаз для `DROP_THEN_TRANSFER`.

Пример:

```text
Перенеси все элементы из A и B в C; D не изменяй; остановись, когда A и B опустеют.
```

Поддерживаются программно зафиксированные глаголы переноса `перемести`, `перенеси`, `перебрось`, `переправь`; удаления `очисти`, `удали`, `ликвидируй`, `избавься от содержимого`; сохранения и остановки, перечисленные командой `ai-brain stage1 language-help --lang ru`.

Пропущенное поле возвращает `CLARIFICATION_REQUIRED`, противоречие возвращает `CONTRADICTORY`, неизвестная операция возвращает `UNSUPPORTED`. Парсер не угадывает смысл. Допускается один типизированный раунд уточнения.
