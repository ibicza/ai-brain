# M-33.6c full disclosed Java rehearsal

This is a development rehearsal over the six source candidates already disclosed in immutable H17. It is not a fresh selector freeze and does not acquire a seventh source body.

The path is provenance verification -> four-axis qualification -> one disclosed-development selector invocation -> physical ingestion/indexing -> oracle-free proposals and field evidence -> identity/conflict/trust closure -> packability -> candidate-pack compilation -> standalone replay -> independently authored JDK oracle -> semantic/trust evaluation -> isolated development installation -> runtime queries.

Production is sealed before any evaluator artifact is authored. Enforced file/process audits require zero golden reads and evaluator dependencies during production. The candidate pack must compile and replay without evaluator state. The exact-I18 Windows and Karina gates use identical selected bytes, deterministic IDs and CPU-only execution; platform-independent outputs are compared structurally and by content hash.

Source-use scope is outside semantic derivation. Re-evaluating the same semantic binding as `PRIVATE_LOCAL_ANALYSIS` and `RAW_SOURCE_REDISTRIBUTION` must preserve the semantic content hash; only raw-export manifests may differ. The task-supplied authorization grants no raw redistribution, so tracked evidence contains derived artifacts and metrics rather than inventing publication authority.
