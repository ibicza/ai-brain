# M-33.6e independent evaluation

Independent evaluation starts only after the ledger contains both production
seals and one `EVALUATION_RESERVED` event. It cannot change qualification,
census, feasibility, selection, proposals, trust decisions, or the candidate
pack.

Each platform reruns the independent JDK-21 SPDX reference and JDK semantic
oracle against the identical H20 pack. Required results include exact SPDX
agreement, zero false automatic identities and unresolved selected licenses,
perfect precision, recall thresholds of 0.95, trust coverage of 0.85, zero wrong
trusted, exact field evidence, exact resolution agreement, successful compile
and replay, and network-free installed runtime queries.

E20 is derived from both evaluation reports, their platform-neutral comparison,
the completed ledger receipt, H20 contracts, security, performance, leak, and
exact-commit quality receipts. Any failed mandatory criterion derives Outcome C.
