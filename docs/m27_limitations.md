# M-27 Limitations

- Exact routing supports finite controlled RU/EN grammars, not general natural-language QA.
- Assistive free-text routing is review-only and untrusted.
- Only bounded local read-only tools execute; there are no web/network or side-effecting tools.
- Tool and skill results never become facts automatically.
- Conflicts have no autonomous winner.
- Multi-intent requests are not partially executed or hidden-planned.
- Orchestration is local and transactional, not distributed.
- One request produces one trusted route.
