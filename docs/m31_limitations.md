# M-31 limitations

- Packs are manually/offline compiled; there is no automatic document or source compiler.
- Chemistry capabilities remain chemistry-specific where the reusable operation is chemistry-specific.
- The two non-chemistry packs prove structure and integration, not broad domain competence.
- There is no neural capability detection, learned/fuzzy authority, runtime network, dynamic weights, or episodic memory.
- Stage 3 does not automatically write FactMemory or RuleMemory.
- Capability receipts grant no execution authority and cannot bypass ToolRegistry or SkillRegistry.
- The pending-action protocol promises at-most-one authoritative publication, not physically exactly-once CPU invocation across process death.
- Registry checksums detect in-database tampering; preventing replacement by an older internally valid whole-file backup requires an external monotonic release anchor.
- No moral, moderation, refusal, political, ideological, or topic restriction is introduced.
