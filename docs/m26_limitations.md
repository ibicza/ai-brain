# M-26 Limitations

- No unrestricted web ingestion or network fetching in the trusted core.
- No autonomous truth discovery or automatic conflict winner.
- No broad natural-language QA or fuzzy trusted entity merge.
- No personal or episodic memory.
- No distributed database; M-26 is one writer with multiple readers.
- No unapproved model writes or model self-approval.
- Source trust tiers are policy metadata, not proof.
- Synthetic benchmarks validate mechanics, not real-world factual accuracy.
- FactMemory does not invoke skills and carries no execution authority.
- Facts remain external to model weights.
- Natural-language extraction, ranking, graph projection, and unified fact/skill/tool routing remain future assistive layers.
