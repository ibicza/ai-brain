# M-29 Exercise Schema

Content-addressed `ExerciseSpec` and `ExerciseInstance` records bind family, structural difficulty, objectives, parameter constraints, accepted answer kind, unit policy, templates, source policy, deterministic seed, hidden exact graph, answer key, equivalents, provenance, split axis, and counterfactuals.

Six families cover fact retrieval, composition, simple/grouped molar mass, mass/amount, and amount/entities. The visible question excludes graph hashes, split/diagnostic labels, and hidden answer fields.
