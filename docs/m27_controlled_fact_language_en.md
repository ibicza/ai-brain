# M-27 Controlled Fact Language: EN

Supported finite exact forms:

- `What is the <predicate> of <entity>?`
- `What was the <predicate> of <entity> on YYYY-MM-DD?`
- `What did the system know about <entity>'s <predicate> at <ISO timestamp>?`
- `Show all <predicate> values for <entity>.`

Entity labels/aliases and canonical predicate names use normalized exact matching only. An ambiguous alias requires clarification. Unknown predicates and fuzzy matches never receive exact authority.
