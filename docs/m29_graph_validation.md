# M-29 Graph Validation

The verifier independently checks content hashes, schema, duplicate IDs/edges, cycles, connectivity, input presence, factual provenance, unit consistency, formula AST recomputation, current domain/source/tool bindings, and the root result.

Decimal multiplication, addition, division, normalization, mole relations, Avogadro relations, and display rounding are recomputed at bounded high precision. Rehashed arithmetic tampering is rejected; the M-29 test battery accepts zero tampered graphs.
