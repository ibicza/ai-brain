# M-33.6d SCM correspondence authority

SCM completeness is recomputed from per-entry correspondence rows, never inferred from candidate analysis or license status. Complete classes are raw exact, canonical-text exact, relocated raw/canonical exact and generated-with-verified-provenance. Unmatched and ambiguous rows remain incomplete.

Every decision records artifact path, repository path, class, selection state, completeness, reason and hash. `VERIFIED_EXTERNAL_CHAIN` requires every selected entry to be complete. The disclosed rehearsal independently accounts for all 1,684 candidate Java entries and 120/120 selected entries.
