# Generic fixture packs

Two test-only packs contain no Python domain implementation. `taxonomy-v1`
proves concepts, IS-A/prerequisite-style structure, classification family, and a
taxonomy capability. `quantity-equation-v1` (deliberately not named physics)
proves quantities, units, a typed equality AST, applicability, and an equation
verification capability.

Both strict-load, resolve capabilities, expose candidates, project progress, and
recommend through the same generic implementations used by chemistry. They are
structural fixtures, not claims of broad subject mastery.
