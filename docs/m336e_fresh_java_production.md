# M-33.6e fresh Java production

Windows and Karina production consume the same frozen F20 implementation,
portable vault manifest, source-entry binding manifest, sealed census,
feasibility proof, selected manifest, and selector receipt. Karina verifies the
selection and never reserves or invokes a second selector.

Production materializes selected bytes only into a temporary external snapshot.
It runs ingest, Tree-sitter source indexing, segmentation, proposal generation,
structural verification, independently recomputed field evidence, conflict and
trust closure, review, candidate-pack construction, exact compilation, replay,
isolated installation, and runtime smoke queries. Evaluator and goldens are
unavailable, network access is denied, and the file/process/state audits must all
remain zero.

Both platform outputs are sealed in the persistent ledger before evaluation can
be reserved. H20 is assembled only from public-safe derived outputs and receipts.
