# M-33.5 component manifest

`JavaProductionComponentManifest` binds release, source paths and content,
bundle/documents, type universe, each source unit and declaration, physical
declarations, segments, proposals, callable identities, evidence requirements
and receipts, conflicts, packability, decisions, trusted set, closure and
candidate pack. The comparator follows this fixed dependency order and returns
the first stage, first identity, field path, left/right hashes and dependency
chain. `NONE` with difference count zero is the cross-platform acceptance state.
