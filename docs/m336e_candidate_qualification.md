# M-33.6e candidate qualification

Every acquired candidate receives ten explicit decisions: authenticity,
analysis eligibility, sealed-vault retention, raw publication, excerpt
publication, derived-pack publication, metrics publication, SCM
correspondence, file-scoped license applicability, and the eligible source-entry
set. H20 contract v2 preserves a typed, hash-bound summary for every candidate;
the candidate denominator must equal the acquisition denominator.

License scope is file-specific. An unknown legal document blocks only files to
which its path domain may apply. It remains inventoried and review-required,
but an unrelated nested document does not poison an otherwise resolved source
path. Every selected file still requires an exact resolved scoped-license
decision and complete SCM correspondence.

Analysis eligibility is not selectability. The later census independently
requires exact parser success, production-index support, callable declarations,
and a declared evidence-policy path before a file can enter the selector.
