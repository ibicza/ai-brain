# M-27 Supersession Domain Policy

A superseding claim must share subject entity, predicate, conflict-key qualifier values, and value kind with the old claim. It must be active, cannot create a cycle, and cannot replace a later valid interval with a wholly older interval.

Cross-entity and cross-predicate supersession is rejected before any relation or status event is written. Conflict resolution through supersession remains limited to the conflict domain containing the reviewed replacement.
