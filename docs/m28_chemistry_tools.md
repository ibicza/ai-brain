# M-28 Chemistry Tools

Four local read-only tools are registered:

- `chemistry_formula_composition`
- `chemistry_molar_mass`
- `chemistry_mass_amount`
- `chemistry_entity_amount`

Every proposal includes a current immutable ChemistryKnowledgeSnapshot. Every descriptor requires explicit confirmation and forbids network access. Transitive manifests bind parser, calculation, knowledge snapshot, model, tool, and version modules. Execution revalidates the proposal, implementation, dependency snapshot, arguments, and chemistry snapshot.
