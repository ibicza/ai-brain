# M-33.6h Karina identity

Karina is selected by stable host evidence, never by an IP address alone. The private endpoint configuration remains outside every worktree. Public evidence contains only the build-host role, hashed hostname, hashed SSH host-key fingerprint, OS family, architecture, public JDK receipt hash, repository identity hash, verification status, and receipt hash.

No remote write is permitted until those identities agree. Address history is reported only as a conclusion about stable identity; endpoint addresses, usernames, private-key paths, home paths, and worktree paths are excluded from public artifacts.
