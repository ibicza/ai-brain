# M-33.6h route state machine

The native rehearsal advances monotonically through preflight, qualification, bindings, census, closure, feasibility, selection, materialization, compiler-aware production, pack verification, sealed replay, platform sealing, independent evaluation, staging, leak scan, and readiness. Selection cannot precede feasibility; evaluation cannot precede both platform seals.

Transitions are explicit and fail closed. Non-authoritative rehearsal ledgers are private and separate from the future final acquisition, selector, and evaluator ledgers. The final mode is a guarded endpoint and is not reachable during M-33.6h rehearsal.
