# IUPAC Identity Mapping

M-28.2 selected **Outcome B** for IUPAC. The official 2022 periodic-table PDF is frozen and hash-bound, but no sufficiently reliable official machine-readable or deterministic table extraction path was established for all required identity fields.

The 33-element fixture is therefore classified as `REVIEWED_MANUAL_MAPPING`, never deterministic extraction. Each atomic number, exact symbol, English name, period, and group has a reviewed PDF table-cell locator and evidence hash.

Approval `approval_iupac_elements_2022` binds the official snapshot, selected values, locators, policy version, mapping hash, reviewer identity/type, decision, and timestamp. A model or blank reviewer cannot approve it; any mapped-value or locator change invalidates approval.

Limitation: this is a bounded reviewed mapping for 33 selected elements, not unrestricted IUPAC extraction.
