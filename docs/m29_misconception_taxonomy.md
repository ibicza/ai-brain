# M-29 Misconception Taxonomy

The typed taxonomy contains formula/symbol/count, atomic-weight/policy, molar-term/sum, operation direction, unit-factor, Avogadro, entity multiplier, rounding, interval, arithmetic, ambiguous, and unclassified outcomes.

Twenty-four category calculators return exact counterfactuals when applicable and explicit no-candidate results otherwise. A diagnosis is emitted only from submitted evidence. Equal counterfactual outputs produce `AMBIGUOUS_DIAGNOSIS`; no learner intent is inferred.

In 3,000 acceptance cases: 2,188 exact, 812 intentionally ambiguous, zero wrong confident, zero unclassified; exact diagnosis precision was 1.0000.
