# M-33.6e performance report

Performance is measured, never substituted for correctness. Receipts record
wall-clock durations and peak Python memory for acquisition, qualification,
production indexing, census/feasibility, selection, production, compilation,
replay, evaluation, runtime, leak scanning, and exact-commit quality gates.

The implementation uses candidate-local failure isolation and a deterministic
feasibility dynamic program. No performance optimization may weaken authority,
license scope, correspondence, parser/index support, evidence policy, selector
cardinality, or leak checks. Q20 and the final run will add the measured Windows
and Karina values.
