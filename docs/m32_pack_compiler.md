# Provisional pack compiler

Only exact approved-proposal closure compiles. The compiler emits IR v2 records, a concept graph, capability requirements, exact source bindings with field evidence, exercise-family proposals, evaluation manifest, and a provisional Domain Pack.

Compilation is deterministic for the same bundle, segments, proposals, approvals, domain ID, version, and timestamp. Installation remains a separate explicit operation requiring pack approval, current provider/capability closure, evaluation, dependency checks, and registry audit.
